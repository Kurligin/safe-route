# Результаты прогонов

Финальный контроллер из корня репозитория. Открытые сценарии 01, 01e, 02, 02e, 03, 04, seed 1–3.
Режим локализации по умолчанию: `LOC_MODE = "odom"` в `config_team.py`.

| Путь | Что там |
|---|---|
| `reports/<сценарий>__s<seed>.json` | отчёт `amrsim run --report`, все 18 прогонов |
| `score/<сценарий>__s<seed>.txt` | текстовый вывод `amrsim run`: миссии, итог и блоки, время шага |
| `logs/<сценарий>__s1.jsonl` | лог `amrsim run --log` для seed 1 каждого сценария (для АРМ) |
| `features/` | прогоны, которые показывают дополнительные возможности, см. [`features.md`](features.md) |
| `scenarios/` | `amrsim batch` по своим сценариям (10 × seed 1–3) и прогоны оракула, см. [`scenarios/README.md`](scenarios/README.md) |
| `tests.txt` | вывод автотестов контроллера (`tests/`) и рабочего места оператора (`arm/tests/`) |

## Как воспроизвести

Команды выполняются из папки симулятора `amrsim-participants`, интерпретатор — Python 3.10 с numpy.
`<repo>` — путь к этому репозиторию.

```bash
# один прогон: отчёт и лог
python -m amrsim run scenarios/02_gnss_shadow.json --controller <repo>/controller.py --seed 1 \
    --report out/02__s1.json --log out/02__s1.jsonl

# весь набор этой папки: 6 сценариев × seed 1–3
mkdir -p out
for sc in 01_clear 01e_clear_easy 02_gnss_shadow 02e_gnss_shadow_easy 03_fog_snow 04_busy_yard; do
  for s in 1 2 3; do
    python -m amrsim run scenarios/$sc.json --controller <repo>/controller.py --seed $s \
        --report out/${sc}__s$s.json > out/${sc}__s$s.txt
  done
done

# batch: папка команды внутри родительской папки команд
mkdir -p teams && cp -r <repo> teams/safe-route
python -m amrsim batch teams scenarios --seeds 1,2,3 --jobs 4 --out out/batch.csv
```

Прогоны детерминированы: при том же seed отчёт совпадает. Свои сценарии лежат в
[`../scenarios/`](../scenarios/README.md); команда та же, только путь к сценарию другой.
