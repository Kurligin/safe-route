# Подход

Контроллер — конвейер на каждый тик 0,1 с: локализация → восприятие → миссия → план → следование → безопасность (`controller.py`). Модули — чистые классы, пороги собраны в `config_team.py`.

**Локализация** (`localization.py`). EKF по состоянию [x, y, θ, масштаб одометрии, уход ИНС, смещение ГНСС по x и y].
- Прогноз по колёсной одометрии, делённой на (1 + масштаб). Масштаб калибруется по собственным командам через закон скорости из config (`motion.py`). Режим `LOC_MODE = "model"` берёт прогноз из команд.
- Скан сопоставляется с картой по растру знакового расстояния 0,1 м (`geometry.DistanceField`). Это итеративный EKF с робастными весами, и информация берётся только по осям, которые скан видит.
- Курс корректируется по ИНС. ГНСС проходит χ²-гейт и детектор скачков, стойкое расхождение позволяет перепривязаться.
- Пересечение известной границы тени ГНСС фиксирует позицию поперёк границы.
- Детектор упора — «бампер по скану» с вето по сравнению двух сканов.
- Режимы «расхождение карты» (берём только точки на стенах) и «потеряна» с корреляционным поиском. Ошибка позы в движении на открытых сценариях не больше 0,37 м.

**Миссия и следование** (`mission.py`, `planner.py`, `follow.py`).
- Сами ведём флаг забора груза. Если миссия началась не у `from`, едем туда по A* на сетке 0,5 м. `arrived` ставим при оценке ≤ 0,12 м от цели, σ ≤ 0,08 м и нулевой скорости по модели; сбрасываем в тот же тик, когда меняется миссия.
- Профиль скорости: предел зоны + 0,04 с торможением к зоне заранее, углы пути, док по √(2ad).
- Regulated pure pursuit, разворот на месте, задний ход и повторный заход в доке.
- Статус считаем по своей модели скорости: `moving`, пока |v| > 0,05.

**Безопасность** (`perception.py`, `safety.py`). Лидарные возвраты, которые карта не объясняет, собираем в кластеры и треки в кадре одометрии; у трека есть центр и скорость, классы — человек или статика.
- Скорость рядом с людьми выбираем по прогнозу их движения на 3 с: зазор не меньше 3,3 м при v > 0,27 и не меньше 0,8 м при любом движении (правила 3 м и 0,5 м с запасом).
- Перед пешеходом, которого видели идущим, если он стоит впереди или идёт навстречу, — стоп в точный ноль.
- Не трогаемся, пока кластер ближе 0,8 м.
- Предмет у оси объезжаем боковым смещением пути внутри дороги (`planner.Bypass`).
- estop — только когда обычным торможением до предмета ближе 1,4 м уже не успеть.
- Корпус держим не ближе 0,3 м к статике и стенам карты: там снижаем скорость до 0,3 м/с. Стопы по людям действуют до самой цели.

**Рассмотрены альтернативы локализации:** фильтр частиц (тот же счёт при 1 000 частиц, но втрое дороже по времени и не переживает «похищение»), минимальная схема без Калмана (ошибка позы в 1,5–2 раза выше), скользящее окно (выигрыша нет). Оставлен EKF: детерминирован, шаг всего контроллера ≈ 0,6 мс.

**Не сделано:** выбор режима локализации на лету, проскок перед пешеходом, отдельная дистанция следования за попутным пешеходом, надёжный объезд поддона, упавшего вплотную к оси перед платформой. Стоящий пешеход, которого ни разу не видели идущим, через 0,9 с считается предметом.
