# Свои сценарии

Витрина «работает / граница» лежит в [`showcase/`](showcase/): описание и прогоны — в
[`../results/showcase/README.md`](../results/showcase/README.md).

10 сценариев в формате amr-1.0 (DATA.md §2) на карте открытых сценариев. Мы их используем для
проверки контроллера и для показа возможностей: см. [`../results/features.md`](../results/features.md).
Поле `hidden` у всех сброшено в `false`: это не сценарии жюри.

## Как получены

- **`gen_*` — скрытоподобные.** Их делает наш генератор по описанию из DATA.md §1:
  - маршрут из двух миссий между складом, магазинами и зарядкой;
  - тень ГНСС на северной или южной дороге;
  - оставленный поддон (`object_dropped`);
  - расхождения карты: новый забор (`add`), снесённый контейнер (`remove`);
  - пешеходы, часть из них невнимательные;
  - туман, снег, окна `gnss_outage`.

  Сценарий допускается тем же фильтром, что у организаторов: **оракул (baseline с истинной позой,
  `--cheat`) набирает больше 85 хотя бы на 2 из 3 seed фильтра**. Из 60 кандидатов прошли 42, здесь 6
  из них. Параметры генерации лежат в поле `generator` каждого файла.
- **`stress_*` — стрессовые, вне фильтра.** Тот же генератор, но условия жёстче: поддон ближе к оси,
  толпа пешеходов. Оракул на `stress_pallet_close_012` получает 0.
- **`own_*` — написаны вручную** на основе `01_clear` под конкретную возможность.

Сам генератор в репозиторий не входит: он импортирует симулятор, а контроллеру такой импорт
запрещён.

## Запуск

Из папки симулятора, `<repo>` — путь к этому репозиторию:

```bash
mkdir -p out teams && cp -r <repo> teams/safe-route   # teams/<имя>/ = копия репозитория
python -m amrsim run <repo>/scenarios/own_pallet_drop.json --controller <repo>/controller.py --seed 1
python -m amrsim batch teams <repo>/scenarios --seeds 1,2,3 --jobs 4 --out out/own.csv
```

## Известное ограничение

Поддон, который падает перед платформой ближе 1 м к оси, этим набором не покрыт. В таком случае
платформа тормозит, но потом может так и не объехать поддон, если остановилась вплотную. Оракул
на таких сценариях тоже получает 0, поэтому фильтр допуска их отсекает.
